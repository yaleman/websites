# Websites

This is a website management system built to replace a jumble of Wordpress and static site generators.

## Features

- Dynamic management but renders to static pages, intentionally simple but supports all the things I've needed.
- Built in [Rust](https://rust-lang.org)
- Wordpress XML imports
- "Clean up" system for fixing old HTML and importing content
- Stores as [Markdown](https://docs.rs/markdown/latest/markdown/index.html) internally
- [Tera](https://keats.github.io/tera/) (Jinja-ish) templating for website design
- OAuth2/OIDC authentication
- Storage in SQLite but extensible

## Why the name?

Couldn't think of a better one, will likely rename it one day!
